# Наша маленькая история

Полный исходный проект Godot 4.7.2 с подготовленной сборкой для браузера и GitHub Pages.

## Публикация
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите содержимое этого архива в корень репозитория (папки `littlehistory` и `.github`, а также `README.md`).
3. В GitHub откройте Settings → Pages и выберите публикацию через GitHub Actions, если GitHub не включил её автоматически.
4. Откройте Actions. Workflow `Build and publish Godot Web game` соберёт игру и опубликует сайт.
5. Адрес сайта будет иметь вид `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Сборка выполняется на GitHub Actions, поэтому локально устанавливать Godot не требуется.
